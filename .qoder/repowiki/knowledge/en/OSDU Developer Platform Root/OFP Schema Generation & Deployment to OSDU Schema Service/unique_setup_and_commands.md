Regeneration needs the parent workspace layout (`~/dv`) or an overridden `OFP_REPO_ROOT`; key style defaults to snake_case (`KEY_STYLE=snake`) to match OFP DB/ELM. Deployment requires `OSDU_TOKEN_FILE` (or `OSDU_TOKEN`), optional `OSDU_BASE` and `OSDU_PARTITION`, and a bearer token whose identity belongs to `service.schema-service.editors`. Run `python3 generate_schemas.py` then `bash register_schemas.sh {test|refdata|transaction|all}` from the repo root.
