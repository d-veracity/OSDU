The module is a static documentation site powered by MkDocs with the Material theme. The root `mkdocs.yml` declares the site metadata, theme customization (Material palette, fonts, features), markdown extensions (pymdownx suite, admonitions, mermaid fences, tabbed blocks), plugins (search, minify), and the full navigation tree under `nav:` that maps to Markdown files in `docs/src/`. Content is organized into top-level sections — Concepts, Installation, Features, Services (with nested OSDU Core/Reference and Experimental subsections), Design, and Tutorials (Deployment, Debugging, Advanced Scenarios) — each backed by a single `.md` file. Static assets live under `src/images/` (screenshots, architecture diagrams, branding logos in multiple formats) and are referenced via relative paths; custom styling is injected through `src/stylesheets/extra.css` and client-side behavior via `src/javascripts/tablesort.js`. The build output directory is not committed; only source Markdown, assets, and configuration are versioned.
