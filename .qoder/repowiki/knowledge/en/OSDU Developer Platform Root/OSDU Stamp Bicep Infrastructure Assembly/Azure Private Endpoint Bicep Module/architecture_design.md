Single-module Bicep package rooted at `main.bicep` with `targetScope = 'resourceGroup'`. The entrypoint declares typed parameters (resourceName, subnetResourceId, serviceResourceId, groupIds, plus optional ipConfigurations, customDnsConfigs, manualPrivateLinkServiceConnections, tags, lock, crossTenant) and emits four outputs (resourceGroupName, name, id, location). It creates one `Microsoft.Network/privateEndpoints@2024-07-01` resource whose name is derived from `resourceName` and stabilized via `uniqueString(resourceGroup().id, resourceName)` and truncated to 24 characters. Optional capabilities are factored into sibling submodules under `.bicep/`: `private_dns_zone_groups.bicep` attaches a `privateEndpoints/privateDnsZoneGroups` child resource referencing the endpoint by name, and `nested_rbac.bicep` iterates over a `roleAssignments` array to create `Microsoft.Authorization/roleAssignments` scoped to the endpoint, supporting built-in role name resolution and cross-tenant delegated managed identity scenarios. A conditional `Microsoft.Authorization/locks` resource applies CanNotDelete or ReadOnly protection when the `lock` parameter is set. Tests in `test/main.test.bicep` compose this module against sibling storage-account and virtual-network modules to exercise end-to-end deployment.
