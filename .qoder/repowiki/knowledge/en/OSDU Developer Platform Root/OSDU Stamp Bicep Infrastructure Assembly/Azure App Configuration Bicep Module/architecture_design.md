Single-entry Bicep module (`main.bicep`) scoped to `resourceGroup` that declares the `Microsoft.AppConfiguration/configurationStores@2024-06-01` resource and composes optional child resources via conditional blocks and nested modules. Two reusable sub-modules live under `.bicep/`: `key_values.bicep` creates individual `configurationStores/keyValues` entries (one per entry in the `keyValues` array), and `nested_rbac.bicep` creates `Microsoft.Authorization/roleAssignments` for each entry in `roleAssignments`, resolving built-in role names via a local map. Optional features are gated by parameters: a resource lock is applied when `lock != 'NotSpecified'`, diagnostics are enabled when any of the diagnostic destination IDs are set, CMEK is enabled when all three `cmekConfiguration` fields are provided, and Private Link (private endpoint, DNS zone, DNS zone group, virtual network link) is activated only when `privateLinkSettings.vnetId` and `subnetId` differ from sentinel values. The module exposes `name`, `id`, and `endpoint` outputs and ships standard registry metadata (`metadata.json`, `version.json`). A `test/` folder contains a minimal test harness that instantiates the module with sample key-values.
