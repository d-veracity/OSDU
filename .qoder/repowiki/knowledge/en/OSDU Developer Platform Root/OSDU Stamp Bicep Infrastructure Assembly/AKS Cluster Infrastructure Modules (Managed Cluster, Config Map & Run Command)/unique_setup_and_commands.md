E2E tests under `managed-cluster/tests/e2e/<scenario>/` and unit tests under `aks-config-map/test/test.sh` / `aks-run-command/test/` require a logged-in Azure CLI session; `test.sh` creates a `bicep-module-testing` resource group in `southcentralus`, runs `az deployment group what-if` (when `WHAT_IF=1`) then `az deployment group create` against the module's `main.test.bicep` and `parameters.json`.
