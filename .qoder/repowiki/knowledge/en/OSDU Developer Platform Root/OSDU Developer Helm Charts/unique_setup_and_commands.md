Charts expect Azure environment values (`azure.tenantId`, `azure.clientId`, `azure.keyvaultName`) to be supplied in values before install; `blob-upload` and `keyvault-secrets` require a pre-created workload identity ServiceAccount named `workload-identity-sa`; `istio-certs` waits for a LoadBalancer IP on `gatewayServiceName` (`external-gateway-istio`) with configurable retry/backoff; `osdu-developer-service` supports per-service configuration via the `configuration` list in values.yaml.
