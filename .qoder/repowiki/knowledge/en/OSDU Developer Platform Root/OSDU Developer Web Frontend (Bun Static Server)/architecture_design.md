Single-file application rooted at `index.ts` using Bun's built-in `serve` to handle all requests. The HTML is inlined as a template string and served for `/`, while image assets under `images/` are served via Bun's `file()` helper for the logo and favicon paths; any other path returns 404. There is no build step — TypeScript runs directly against the source. Deployment is containerized via `Dockerfile` (based on `oven/bun:1`) and can be orchestrated with `docker-compose.yaml`. Dependencies are declared in `package.json` with only `@types/bun` as a dev dependency and TypeScript as a peer dependency, confirming a zero-dependency runtime approach.
